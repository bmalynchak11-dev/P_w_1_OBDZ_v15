# Опис предметної області дипломного проєкту: Система персональних фінансів

Користувач реєструється в системі та керує власними рахунками, фінансовими категоріями й бюджетами.
Кожен користувач має унікальний ідентифікатор, ім'я та адресу електронної пошти.
Користувач може створити довільну кількість рахунків (готівка, банківська картка, ощадний), але кожен рахунок належить суворо одному користувачеві.
Кожен рахунок обов'язково характеризується поточною валютою, балансом та назвою.
Користувач визначає перелік категорій транзакцій (дохідні або витратні); кожна категорія прив'язана до одного користувача.
Кожна транзакція фіксує рух коштів, має дату, суму, тип операції та обов'язково пов'язана з конкретним рахунком і категорією.
Окрема транзакція може містити один або кілька деталізованих рядків (розподіл чека), де кожен рядок транзакції слабко ідентифікується через саму транзакцію.
Користувач може встановлювати щомісячні бюджети на окремі категорії для контролю витрат.
Встановлення ліміту бюджету для категорії є необов'язковим, проте один бюджетний ліміт стосується лише однієї категорії.
Користувач може генерувати періодичні аналітичні звіти, кожен з яких формується для одного облікового запису.
